Bước 4: Hướng dẫn vận hành hệ thống thực tếCấu hình thông số: Mở file config.php, nhập đúng mã Token Bot Telegram của bạn, mã Chat ID của bạn, và nhập 3 mã Device ID thật của 3 cảm biến cửa vào lệnh SQL ở bước 1.Đưa hệ thống lên Internet: Bạn upload toàn bộ các file PHP này lên Hosting của mình.Cài đặt liên kết Webhook: Truy cập trang web nhà phát triển iot.tuya.com, chọn dự án của bạn -> Vào mục Message Service -> Trong mục cấu hình Webhook URL, bạn dán đường dẫn file xử lý ngầm vào (Ví dụ: https://ten-mien-cua-ban.com/tuya_webhook.php) và chọn lưu lại kích hoạt.Kiểm thử vận hành:Bạn dùng tài khoản nhanvien đăng nhập hệ thống, gán trạng thái Phòng 101 là Có khách. Khi bạn mở cửa thật Phòng 101, trang web Dashboard sẽ tự xuất hiện lịch sử mở cửa sau 2-3 giây mà không cần F5. Điện thoại của bạn hoàn toàn im lặng không báo động gì cả.Tiếp theo, bạn dùng tài khoản gán trạng thái Phòng 101 về lại Phòng trống. Bạn tiến hành mở cửa thật Phòng 101 $\rightarrow$ Lập tức điện thoại của bạn sẽ rung lên nhận tin nhắn từ Telegram, đồng thời trên màn hình máy tính Dashboard sẽ tự động nhảy thêm một dòng lịch sử mới được tô đậm màu hồng đỏ cảnh báo rất trực quan.
